# E-Commerce Sales & Management Dashboard

An interactive **Excel-based E-Commerce Sales & Management Dashboard** designed to transform raw transactional data into meaningful business insights through data cleaning, KPI analysis, performance tracking, and interactive visualizations.

## 📊 Project Overview

This project analyzes an e-commerce dataset containing **51,290 records** and converts the raw transactional data into a professional management dashboard.

The workbook follows a structured data-analysis workflow:

**Raw Data → Data Cleaning → KPI Calculation → Business Analysis → Dashboard & Insights**

The dashboard provides an executive-level view of sales, profitability, customer/order performance, product categories, segments, regions, and monthly trends.

---

## 🎯 Business Objective

The main objective of this project is to build a management-friendly dashboard that helps users:

* Monitor overall sales and profitability
* Track key business KPIs
* Analyze monthly sales performance
* Compare product categories
* Understand customer segment contribution
* Identify high-performing regions
* Identify top-performing products
* Evaluate operational metrics such as discounts and shipping time
* Convert raw e-commerce data into actionable business insights

## 🧹 Data Analysis Process

The workbook follows a structured analytical pipeline.

### Step 1 — Raw Data

The original e-commerce dataset is stored in the `Raw_Data` sheet.

### Step 2 — Data Cleaning

The `Clean_Data` sheet is used as the cleaned data source for downstream calculations and dashboard analysis.

### Step 3 — KPI Calculation

The `KPI_Summary` sheet calculates major business indicators such as:

* Sales
* Profit
* Profit Margin
* Orders
* Customers
* Average Order Value
* Average Discount
* Average Shipping Days

### Step 4 — Business Analysis

The `Analysis` sheet contains supporting ranking tables used for:

* Top regions
* Top products
* Sales
* Profit
* Category performance
* Segment performance

### Step 5 — Dashboard

The final dashboard presents the analysis through visualizations and management-oriented KPI cards.
